# Telegram Command Guide (Expanded)

Existing commands remain available:

- `/start`
- `/plans`
- `/upgrade`
- `/faq`
- `/help`
- `/risk`
- `/alerts`
- `/status`

New additive commands:

- `/learn` – send a beginner lesson prompt
- `/pulse` – send beginner market pulse summary
- `/signals` – explain analyst-reviewed setup format
- `/explain` – AI coach explainer entrypoint text
- `/practice` – practice-mode guidance
- `/journal` – journaling prompt
- `/account` – subscription and Telegram status entrypoint

All command messaging remains educational and risk-aware.
